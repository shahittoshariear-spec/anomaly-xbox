# Anomaly Xbox — modifications to XStreaming

Base: [Geocld/XStreaming](https://github.com/Geocld/XStreaming) commit
`06ef1c7ee01d09cf9bb2a97fc4895da85e8488a8` (tag `v2.12.0`), AGPL-3.0.

This document lists the changes made for the personal Anomaly Xbox build. The upstream
project and its contributors remain the authors of the streaming engine and UI.

## App identity

- `android/app/build.gradle`
  - prod `applicationId`: `com.xstreaming` → `app.anomaly.xbox`
  - dev `applicationId`: `com.dev.xstreaming` → `app.anomaly.xbox.dev`
  - `versionCode` 1, `versionName` 2.12.0 (matches the upstream base)
- `android/app/src/main/res/values/strings.xml`: `app_name` is **Anomaly Xbox**.
- `app.json`: `displayName` is **Anomaly Xbox**; the internal React Native name stays
  `xstreaming`, so `MainActivity.getMainComponentName()` is unchanged.
- `android/app/src/main/AndroidManifest.xml`: `roundIcon` now points at
  `@mipmap/ic_launcher_round`.

## Icons and splash

- Replaced all `mipmap-*` launcher assets with the supplied Anomaly Xbox icon set,
  including `mipmap-anydpi-v26/ic_launcher.xml`, `ic_launcher_round.xml` and the
  monochrome layer.
- Replaced `res/layout/launch_screen.xml` and `res/layout-land/launch_screen.xml` with a
  dark `#05080B` screen and the Anomaly foreground icon. The old `screen.png` /
  `screen_land.png` assets remain in the tree but are no longer referenced.

## UI branding

- `src/pages/About.tsx` and `src/pages/AboutZh.tsx`: hero title is **Anomaly Xbox**, the
  version badge is `v2.12.0`, and the upstream card is labelled **XStreaming upstream**.
- `src/languages/en.ts`: the value of `'About XStreaming'` is **About Anomaly Xbox**. The
  key is unchanged so other translation files and code keep working.
- The default theme already uses Xbox green (`#107C10`), matching the icon set.

## Update checker

- `src/store/settingStore.ts`: `check_update` defaults to `false`. This prevents a fork
  install from being offered the upstream XStreaming APK. The setting is still available
  in the app.
- `src/utils/updater.ts` now checks `shahittoshariear-spec/anomaly-xbox` instead of the
  upstream feed, so enabling updates cannot offer the XStreaming APK. The repository does
  not exist yet, so a check simply returns no releases.
- `src/pages/History.tsx` still points at the upstream release feed for reading history.

## Native libraries instead of a Rust/CMake build

`android/app/build.gradle` no longer runs CMake or Cargo:

- removed `externalNativeBuild` blocks, `sourceSets.main.jniLibs` generated directories,
  `ndkVersion`, and the `preBuild.dependsOn("syncSdl2JniLibs")` /
  `syncNanoRustJniLibs` dependencies
- the task definitions remain in the file for reference but are not wired into the build
- added `android/app/src/main/jniLibs/<abi>/libnano_rs.so` and `liblsfg-android.so`,
  extracted from the official `XStreaming-2.12.0.apk` release
- `libSDL2.so` for both ABIs is copied from `third-party/sdl`; its SHA-256 matches the
  library inside the official release APK exactly

This keeps the Java/Kotlin/JNI contract identical to upstream v2.12.0 while allowing a
Windows build without Rust targets, NDK 23.1, or a C++ toolchain. The source native code
(`nano-rs`, `android/app/src/main/cpp`, `third-party/sdl`) remains in the tree.

## Build environment

- `android/build.gradle`: buildscript repositories changed from the Aliyun mirrors to
  `google()` + `mavenCentral()`, and an `allprojects` repository block was added.
- `patches/react-native-paper+5.12.5.patch`: the upstream patch had a malformed hunk
  header (line counts did not match) which `patch-package` 8 rejects. The hunk was
  corrected to apply the same one-line padding change.
- `yarn.lock` was regenerated by `yarn install` (upstream's lockfile did not match
  `package.json`).
- `.yarnrc.yml` disables the global Yarn cache so dependencies live in the project.
- `.gitignore` now excludes the Yarn cache, build outputs, and release keystore.

The release keystore (`android/app/xstreaming-release-key.keystore`) is generated locally
and is not part of the source. Passwords are only in `android/gradle.properties` for this
personal build.
